# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261020/F-series-20261020.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.vbs をダブルクリック。
- 筆：F-series/Fude/Fude.vbs をダブルクリック。

使い方と保存先は各フォルダの README.txt に記載しています。必要なモデルと実行用DLLは同梱済みです。旧版を使用中の場合は終了してから、新しい版を起動してください。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

今回の更新では、付箋の新規作成・畳み方・設定と保存先・日時の選択・文章の装飾と拡縮、筆のピン留めとライブ変換の表示を見直しました。

Windowsの通常起動で、付箋の編集・日本語変換・文字選択・保存・再起動と、筆の表示・切替・終了を確認しています。

実キーボードでの通常の変換入力、付箋のCopy・Ctrl+Enterと筆との組合せ、複数画面・異なるDPI、職場のPC、実際の話し声での音声入力は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
