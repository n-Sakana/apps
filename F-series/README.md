# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（zip）](https://github.com/n-Sakana/apps/releases/download/f-series-20261019/F-series-20261019.zip)

Windows 10 / 11 の 64-bit 版で、zip をすべて展開して使います。

- 付箋：`F-series/Fusen/Fusen.vbs` をダブルクリック。
- 筆：`F-series/Fude/Fude.vbs` をダブルクリック。

使い方と保存先は、zip 内の各フォルダの `README.txt` を参照してください。必要なモデルは同梱済みです。

この版には、付箋の枠線・角・Copy ボタンの描画、筆の周囲の透明な影でクリックが下のアプリに届かない部分など、調整中の点があります。筆のライブ変換・音声入力は、使えるまで 10〜20 秒かかることがあります。職場のパソコンでの動作と、実際の話し声での音声入力は未確認です。
