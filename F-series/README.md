# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261024b/F-series-20261024b.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.cmd をダブルクリック。
- 筆：F-series/Fude/Fude.cmd をダブルクリック。

起動のあいだ小さな画面に進み具合が出て、起動すると閉じます。

この版の主な更新です。

- 筆：日本語の文字が入ったフォルダに置くと、音声入力を始められませんでした。直しました。
- 付箋と筆：開け閉めやメニュー、筆の花びらの動きを、少し時間をかけてなめらかにしました。
- 付箋：閉じる途中で一度カクついて見えることがありました。本文・角・日付の消える時間を揃えました。
- 付箋：モードを Draft と Run の二つにしました。チェック、日付、リマインドの通知、日付のピッカーは Run で使えます。前の版で ToDo だった付箋は、Run で開きます。
- 筆：入力の花びらのヒントを、ほかの花びらと同じ英語にしました。

詳しくは ZIP の中の README.txt にあります。

付箋は、前の版が動いているときに新しい版の Fusen.cmd を起動すると、前の版を閉じてから起動し、前の版のメモを新しい版にまとめます。前の版と同じ場所に展開し直した場合も同じです。筆は、前の版を終了してから新しい版を起動してください。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

Windows のミニ PC で実際に起動して確認しています。日本語・空白・OneDrive の形の名前が入ったフォルダでの音声入力は、録音した音声ファイルで確かめました。職場のPC（Excel の Copilot・Teams）、本物のキーボードとマウスでの操作、本物の2枚目のモニター、本物のマイクと実際の話し声での音声入力は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
