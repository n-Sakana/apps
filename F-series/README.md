# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261021b/F-series-20261021b.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.vbs をダブルクリック。
- 筆：F-series/Fude/Fude.vbs をダブルクリック。

付箋は、前の版が動いているときに新しい版を起動すると何も出ない不具合を直しました（2026-10-21 10時台の更新）。前の版は先に閉じずに、そのまま新しい版の Fusen.vbs を起動してください。前の版を閉じてから起動し、前の版のメモを新しい版にまとめます。筆は、前の版を終了してから新しい版を起動してください。

使い方と保存先は各フォルダの README.txt に記載しています。必要なモデルと実行用DLLは同梱済みです。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

今回の更新では、付箋と筆の中の作りを整理して、軽く・速くしました。使い方と保存先は前の版と同じです。付箋の名前を変えたときにファイル名がすぐ変わらない不具合を直し、筆が何もしていないときのCPUの使用を減らしました。

Windowsのノートパソコンで、付箋の新規作成・日本語変換・移動と拡大・Pin・Copy・名前の変更・ToDo・日時・一覧の窓・削除と元に戻す・リマインダー・保存と再起動、筆のライブ変換の切り替え・履歴・撮影・ピン留め・移動・二重起動・終了を、実際に起動して確認しています。

職場のPC、実キーボードでの通常の変換入力、複数画面・異なるDPI、実際の話し声での音声入力、筆のタスクトレイから玉を隠す操作は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
