# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261021c/F-series-20261021c.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.cmd をダブルクリック。
- 筆：F-series/Fude/Fude.cmd をダブルクリック。

起動は .vbs から .cmd に変わりました。起動のあいだ小さな画面に進み具合が出て、起動すると閉じます。

今回の更新では、モニターを外したり解像度や拡大率が変わったりしたときに、付箋と筆が画面の外に取り残されたり、押しても当たらなくなったりする不具合を直しました。付箋には Quit Fusen（… のいちばん下）を足し、文字を選んだときの窓のずれ、View の見た目、リマインダーとピッカーの表示を直しました。筆は、ライブ変換と音声入力をどちらか一方だけオンにし、範囲の撮影を軽くし、英字まじりの入力を英字と日本語に分けて変換します。詳しくは ZIP の中の README.txt にあります。

付箋は、前の版が動いているときに新しい版の Fusen.cmd を起動すると、前の版を閉じてから起動し、前の版のメモを新しい版にまとめます。前の版と同じ場所に展開し直した場合も同じです。筆は、前の版を終了してから新しい版を起動してください。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

Windowsのノートパソコンで実際に起動して確認しています。職場のPC、本物のキーボードでの通常の変換入力、実際の話し声での音声入力、モニターの抜き差しそのもの（解像度の往復で確認）は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
