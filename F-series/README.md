# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261023b/F-series-20261023b.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.cmd をダブルクリック。
- 筆：F-series/Fude/Fude.cmd をダブルクリック。

起動のあいだ小さな画面に進み具合が出て、起動すると閉じます。

前の版の付箋には、付箋が多いときや本文が長いときに保存が途中で止まり、書いた内容が再起動で消えることがありました。この版で直したので、前の版を使っている場合は入れ替えてください。保存できなかったときは付箋の帯に赤い字で「未保存」と出て、押すと保存し直します。保存し終わるまで Quit では閉じません。

ほかの主な更新です。

- 付箋：画面の文字を、同梱した Noto Sans JP で表示します。
- 付箋：窓の端や角を素早く動かしても、大きさの変更が途中で止まりません。2画面のあいだで窓を移せます。
- 付箋：起動したときの復元が途中で止まる不具合と、コピーして削除した付箋が一覧に残る不具合を直しました。
- 筆：変換中に別のアプリへ切り替えても、確定していない字が消えません。元の欄へ確定します。
- 筆：範囲の撮影で、2画面をまたぐ範囲や、筆のいない画面の範囲も撮れます。すぐ離しても、離した所まで撮れます。
- 筆：玉が一度ほかの方向へ跳ねる、放っておくと玉が隠れる、変換中と確定後で字が上下にずれる、「と」が「ト」になる、を直しました。

詳しくは ZIP の中の README.txt にあります。

付箋は、前の版が動いているときに新しい版の Fusen.cmd を起動すると、前の版を閉じてから起動し、前の版のメモを新しい版にまとめます。前の版と同じ場所に展開し直した場合も同じです。筆は、前の版を終了してから新しい版を起動してください。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

Windows のミニ PC で実際に起動して確認しています。付箋と筆をほかのアプリと並べて1か月分の仕事に使う流れも、日付を進めながら2回通しました（実際に30日待ったわけではありません）。職場のPC、本物のキーボードとマウスでの操作、本物の2枚目のモニター、実際の話し声での音声入力は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
