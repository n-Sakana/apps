# F シリーズ

付箋（Fusen）と筆（Fude）の Windows 向け試用版です。

[まとめてダウンロード（ZIP）](https://github.com/n-Sakana/apps/releases/download/f-series-20261024/F-series-20261024.zip)

Windows 10 / 11 の64-bit版で、ZIPをすべて展開して使います。

- 付箋：F-series/Fusen/Fusen.cmd をダブルクリック。
- 筆：F-series/Fude/Fude.cmd をダブルクリック。

起動のあいだ小さな画面に進み具合が出て、起動すると閉じます。

この版の主な更新です。

- 付箋：開け閉めのときに窓がちらつかなくなりました。
- 付箋：Ctrl+Alt+G、帯の … の Gather folded、一覧の窓の整列のボタンで、畳んだ付箋を主の画面の左上に集めます。開いている付箋と Pin した付箋は動きません。
- 付箋：太字・斜体の行の終わりで Enter を押すと、次の行は普通の字から始まります。
- 付箋と筆：画面を描く部品（MiniUI）を新しくしました。
- 筆：ライブ変換と音声入力を一つの花びらにまとめました。押すたびに オフ → ライブ変換 → 音声入力 → オフ と切り替わります。
- 筆：「setto」が「setと」のまま残らず、「セット」になります。
- 筆：ウィンドウ別と全面の撮影で、筆のいない画面も撮れます。
- 筆：入力先のアプリの応答が遅いときに、確定の Enter が改行や送信になる原因と、ウェブの入力欄で変換中の字がほかの場所に出る原因を直しました。
- 筆：音声入力を始められなかったときは、どこで止まったかを記録に残します。

詳しくは ZIP の中の README.txt にあります。

付箋は、前の版が動いているときに新しい版の Fusen.cmd を起動すると、前の版を閉じてから起動し、前の版のメモを新しい版にまとめます。前の版と同じ場所に展開し直した場合も同じです。筆は、前の版を終了してから新しい版を起動してください。筆の単語・設定・履歴を引き継ぐ場合は、起動前に旧Fudeのuserフォルダを新しいFudeへコピーしてください。

Windows のミニ PC で実際に起動して確認しています。職場のPC（Excel の Copilot・Teams）、本物のキーボードとマウスでの操作、本物の2枚目のモニター、実際の話し声での音声入力は未確認です。すべての操作を網羅した版ではなく、実際に使ってフィードバックするための試用版です。
