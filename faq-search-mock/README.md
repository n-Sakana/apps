# ふだんの言葉で探せる FAQ 検索のモック

困っていることをふだんの言葉で入力すると、当てはまりそうな Q&A を 3 件まで出す検索画面のモックです。
架空の自治体「みなと市」の手続き案内を題材にしています。実在の団体・人物とは関係ありません。

## 開き方

`index.html` をダブルクリックして、ブラウザで開いてください。いちばん新しい版が開きます。
サーバー、ビルド、ネットワーク接続は要りません。外部の読み込みはありません。
スマートフォンで見るときは、このフォルダをそのまま配信して `index.html` を開きます。

## ファイルと版

| ファイル | 中身 |
| --- | --- |
| `index.html` | いちばん新しい版（いまは `v11.html`）へ移るだけの小さなページ。URL の指定はそのまま引き継ぎます |
| `v1.html` | 版 1：最初の案。分野・候補・答えを常に並べて出す |
| `v2.html` | 版 2：情報を選別した案。必要なときに必要なものだけを出す |
| `v3.html` | 版 3：動きと案内を足した案 |
| `v4.html` | 版 4：待ち時間と分野の見え方を変えた案 |
| `v5.html` | 版 5：読み取りと束ねを試す案（版 4 に、試みを 3 つ足したもの） |
| `v6.html` | 版 6：余白と密度を試す案（版 4 のふるまいのまま、左に候補・右に答えの 2 画面） |
| `v7.html` | 版 7：版 6 の直し（長い質問・切り替え方）。位置を固定し、答えの紙の中で送れるようにした |
| `v8.html` | 版 8：版 7 の直し。「ほかの候補」と分野の一覧は下へ伸びて全部見える。送りのつまみは紙の内側の専用の場所。たたんだ長い質問は 2 行まで見せる |
| `v9.html` | 版 9：端からめくれるページ。紙の替わり方をデモ用パネルで選べる（めくる・フェード・スライド・せり上がり・拡大・タイプライター）。候補の一覧は紙の下の端とそろう |
| `v10.html` | 版 10：スマートフォンの置き方を詰めた版。結果が出ると見出しがたたまれ、入力欄・分野・候補が 1 行ずつになって、答えの紙が画面の上のほうから始まる。紙の上で左右に払うと候補が替わる |
| `v11.html` | 版 11：版 10 の直し。打っているあいだは結果を描き直さず 3 つの点だけを出す。紙の替わり方はフェード（はじめ）とめくる（いつも右下の角から上へ）の 2 つ。スマートフォンの候補の帯は右の端がうすく消える。入力欄の例は、何もしない時間が続いたときだけ打たれる。デモ用パネルは、版と紙の替わり方をプルダウンで選ぶ。パネルを出すかどうかは、ファイルの先頭近くの `var SHOW_DEMO_PANEL = true;` の 1 行で切り替える。パネルの見本の質問は、データの `site.extras.demoSamples` から取る |

- どの版も、そのファイルだけで動きます。
- 版は、デモ用パネルのいちばん上にある「版」のボタンで切り替えられます。入力中の質問、明るさ、絞り込んだ分野は引き継がれます。
- 版を足すときは、新しいファイルを置き、各ファイルの `VERSIONS` の配列に 1 行足し、`index.html` の `LATEST` を書き換えます。

URL の末尾に次の指定を付けられます。

| 指定 | 意味 |
| --- | --- |
| `?q=住民票ってコンビニで取れる？` | その質問を入力した状態で開く |
| `?cat=gomi` | 分野を絞り込んだ状態で開く |
| `?demo=0` / `?demo=1` | デモ用パネルを出さずに開く／開いた状態で開く |
| `?theme=dark` / `?theme=light` | 明るさを指定して開く |
| `?tour=1` | 使い方の案内を始めた状態で開く（版 3 から） |
| `?view=phone` | パソコンで、iPhone の大きさの枠の中に表示する（版 3 から） |
| `?data=data/faq.json` | 外のデータを読み込んで開く（版 3 から。http で開いたときだけ。このページから見た場所を書く） |
| `?relay=<中間サーバーの URL>` | 中間サーバーに問い合わせて動かす（版 3 から。確認用） |
| `?turn=peel` ほか | 紙の替わり方を指定して開く（版 9。`peel` `fade` `slide` `rise` `zoom` `type`） |
| `?peel=0.5` | 紙が替わる動きを、その進み具合（0〜1）で止めて見る（版 9。確認用） |

## 版 4 の画面

ふだん見えているのは、見出し、入力欄、そのすぐ下にうすく並ぶ分野の名前だけです。

- 打っているあいだは、結果を出しません。小さな 3 つの点が動くだけです。手を止めると、さがして結果を出します。また打ちはじめると、結果は引っこみます。
- 分野の名前は、入力がどの分野の話に見えるかに合わせて、打つそばから濃くなります。名前を押すと、その分野に絞ります。入力が空のときに押すと、その分野の Q&A が並びます。
- 結果は 1 枚の「紙」に載ります。上に候補が 3 件まで並び、選んだ候補の答えがその下に出ます。紙に載っているものが Q&A、紙の外が道具です。
- 候補は `↑` `↓`（入力欄の外では `←` `→` も）、クリック、スマートフォンでは左右に払う操作で、その場で切り替わります。
- 候補の題名は、ほかの候補と同じ部分を控えめに、ちがう部分をはっきり出します。
- 答えの中で、入力した言葉が出てくるところに、うすい印を付けます。
- 候補が絞りきれないときは、候補の題名に出てくる言葉を「＋市内」のように出します。押すと、その言葉を足してさがし直します。
- Q&A の文は、もとの文のまま出します。画面が足すのは、印と並べ方だけです。
- 「よく見られている Q&A」は、何も操作しない時間が 4 秒ほど続いたときだけ出ます。ポインターを動かすだけでも消えます。
- 当てはまり具合は「よく当てはまる」「当てはまりそう」「近い話題」の言葉と 3 つの目盛りで出します。
- 見つからないときは、その旨を大きく出し、言い方の例と「窓口に問い合わせる」を出します。
- 右上の「使い方を見る」で、実際の画面を使った 20 秒ほどの案内が流れます。
- iPhone で使えるようにしてあります。動きを減らす設定にしているときは、アニメーションを使いません。

## 版 5 で試していること

版 4 の画面に、次の 3 つを足しています。どれも手元の採点から作った目安で、Q&A の文は変えていません。

- 読み取りの札：質問を「対象」と「状況」にどう読んだかを、小さな札で出します。札を押すと、ほかの読み方が割合つきで並び、選ぶとその読み方でさがし直します。読み取れなかったときは出しません。取り込んだデータでは出ません。
- 用件の束ね：1 つの質問がいくつかの分野にまたがるときは、候補を 1 つの一覧として出し、読んだものに印を付けられます（ページを開いている間だけ覚えます）。並びは当てはまり具合の順です。
- 答えの中の印：質問の言葉がいちばん多く出てくる文（2 つまで）に、うすい印を付けます。紙の下の「印を消す」で消せます。
- 候補の題名は、選んでいる行をいちばん目立たせ、ほかの候補と同じ言い回しを控えめにしています。

## 版 6 の配置

ふるまいは版 4 と同じで、置き方だけを変えています（版 5 の試みは入っていません）。

- 広い画面：左に入力欄・分野・候補、右に答えの紙の 2 画面です。候補には、答えの最初の 1 文をそのまま 1 行で添えます。
- 右の紙には、いつも選んでいる候補の答えが出ます。`↑` `↓` で候補を替えると、紙もすぐ替わります。候補の上でポインターを少し止めると、下見として紙に出ます。
- 何も入力していないときは、中央に細い 1 列だけです。右の紙はありません。最初の結果が出るときに、列が左へ寄って 2 画面になります。入力を消すと中央に戻ります。
- 狭い画面：1 列になり、候補は紙のすぐ上で左右に払える帯になります。

## 版 7 で変えたこと

版 6 の 2 画面をもとに、次を変えています。

- 位置は動きません。広い画面では、左の列（見出し・入力欄・分野・候補）と右の紙は、いつも同じ場所です。何も入力していないとき、右は空いています。ページ全体は送られず、答えは紙の中で、候補は一覧の中で送ります。
- 送りのつまみは、動かしているあいだだけ出ます。
- 入力欄は 1 行ぶんの場所のままです。長い質問は、入力欄がその場で下へ重なって伸びます（5 行まで。200 文字まで）。ほかの部分は押し下げません。さがしたあとは 1 行に戻り、入力欄を押すとまた開きます。`Enter` でさがし、`Shift` + `Enter` で改行します。
- 候補の上にポインターを置いただけでは、紙は替わりません。クリック、`↑` `↓`、スマートフォンでは払う操作で替わります。
- 紙は、ページをめくるように替わります。
- 候補の下の「ほかの候補」を押すと、4 位より下の候補も同じ一覧の中に出ます（弱すぎるものは出しません）。
- 分野の名前を押したとき：入力が空なら、その分野の Q&A が並びます。入力があるときは、その分野に絞ります。絞って何も無いときは、そのことを伝えて、その分野の一覧を出します。
- 「よく見られている Q&A」は、1.3 秒ほど何もしないと出ます。入力欄に入る、ほかの場所を押す、キーを打つ、送る、で消えます。一覧へ向かうポインターの動きでは消えません。
- スマートフォン：答えを読みすすめても、質問の 1 行と候補が上に残ります。帯の下の点で、候補がいくつあるかが分かります。

## データの出どころを切り替える（版 3 から）

画面は、データの取り出し口（サイトの情報・分野の一覧・記事・質問の 4 つ）だけを呼びます。
取り出し口の中身は 2 つあり、スクリプトの先頭の 1 行で選びます。

```js
var SOURCE = { kind: "builtin" };                      // このファイルの中のデータと採点処理を使う
var SOURCE = { kind: "relay", baseUrl: "https://…" };  // 中間サーバーに問い合わせる
```

- `builtin`：ネットワークを使いません。
- `relay`：画面はデータも鍵も持たず、中間サーバーにだけ話しかけます。中間サーバーに求めるのは、次の 4 つです。
  - `GET /api/site`（サイト名・分野・よく見られている問い）
  - `GET /api/categories/<id>`（その分野の問いの一覧）
  - `GET /api/articles/<id>`（記事の本文）
  - `POST /api/ask`（質問を送ると、分野・候補 3 件まで・「どれにも当てはまらない」の割合が返る。版 7 は、4 位より下の候補 `more` も使います。`more` には答えの文が無いので、選んだときに記事を読みます）
- 中間サーバーを使うときのふるまい：
  - 質問を送るのは、入力が止まってからです。1 文字だけの入力と、同じ質問は送りません。
  - 断られたときは、その旨を落ち着いた言葉で出します（こみ合っている／いまは受け付けていない／つながらない）。
  - 合言葉を求められたら、合言葉の画面を出します。合言葉は、ファイルにも URL にも書きません。入れた合言葉は、そのブラウザーにだけ覚えさせます。

## 外のデータを読み込む（版 3 から）

`builtin` のときは、見本のデータを外のデータに入れ替えられます。

- デモ用パネルの「データを読み込む」で、JSON または JSONL（`faq-search/1` の形）のファイルを選ぶか、パネルに落とします。
- http で開いているときは、`?data=<このページから見た場所>` でも読み込めます。
- サイト名・分野・Q&A が入れ替わります。`keywords` は言い換えとして採点に使い、`views` は「よく見られている Q&A」の並びに使います。
- 版 11 から、`site.extras` も読みます（どれも書かなくてよい）。`demoSamples`（デモ用パネルの見本の質問。文字の並び。メモを添えるときは `{ "q": "…", "note": "…" }`）、`placeholders`（入力欄の例）、`examples`（見つからないときの言い方の例）、`tourSample`・`tourNotFound`（使い方の案内で打つ質問）。書いていないものは、よく見られている Q&A から作ります。中間サーバーのときは、`/api/site` が返す `site.extras` を使います。
- 答えの文は、段落・`- ` の箇条書き・`1. ` の番号つき・`## ` の小見出しに分けて、文字として出します。HTML としては解釈しません。
- 形がおかしいときは、どの行・どの項目かを添えて知らせ、いまのデータのまま表示を続けます。

## デモ用パネル

画面の右端（狭い画面では右下）の「デモ」を押すと開きます。点線で区切られた部分で、製品の画面には含まれません。

- 版の切り替え、表示の切り替え（パソコン／iPhone の枠）。
- サンプルの質問を押すと、検索欄に 1 文字ずつ入力します。使い方の案内も再生できます。
- 直前の検索について、送る内容と返ってくる内容、応答時間、費用の目安を見られます。
- データの読み込み、応答の速さ、「該当なし」のしきい値。
- 「完全に隠す」で消せます。Shift + D か再読み込みで戻ります。

## 本物ではない部分

- `builtin` のときは、分類モデルを呼び出していません。当てはまり具合と分野の割合は、ファイルの中の採点処理（言い換えの表と、文字の並びの重なり）で作っています。
- 応答までの待ち時間は、それらしい長さを乱数で作っています。
- デモ用パネルの送受信の内容と費用は、実際に動かした場合を想定した見本と試算です。
- お問い合わせフォームは、どこにも送信しません。
- 見本のデータの、見られた回数、手数料、窓口、日付などの数字はすべて架空です。
