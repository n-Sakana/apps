# ライブ変換

Windows で、打つそばから日本語を変換します。変換・辞書・学習は手元で動き、ネット接続、管理者権限、追加ソフトのインストールは不要です。

## ダウンロード

- [従来版](live-henkan-classic.zip)：かな・英数を手動で切り替えて使います。
- [日英混在版](live-henkan-mixed.zip)：日本語と英語を続けて入力できます。F10／F6 で選び直した単語の言語を覚えます。

## 始め方

1. 使う版の zip をダウンロードし、すべて展開します。
2. 展開したフォルダの `install.bat` をダブルクリックします。
3. デスクトップの何もないところを右クリック →「ライブ変換」→「オンにする」で始めます。Windows 11 では「その他のオプションを確認」の中です。

止めるときは「オフにする」。右クリックの登録を外すときは `uninstall.bat` を実行します。

二版の設定・辞書・学習は、それぞれのフォルダに保存します。同時には常駐できません。版を替えるときは先にオフにして、使う版の `install.bat` を実行してください。

Windows 10／11（64-bit）用です。メモ帳では文書の中で、Word・Excel・ブラウザーではカーソル位置に重ねて変換中の文字を表示します。候補選択や辞書登録の使い方は、各フォルダの `README.txt` にあります。

同梱の変換モデルは jinen-v2-xsmall を変換したものです（CC BY-SA 4.0）。出典・変更点は各フォルダの `THIRD-PARTY.txt` に記載しています。
