# C シリーズ

Copilot Chats の試用版です。Teams のチャットとチャネルを、Microsoft 365 Copilot の画面に並べて使えます。

[ダウンロード（2026-11-05 の版）](https://github.com/n-Sakana/apps/releases/tag/c-series-20261105)

ZIP をすべて展開し、Copilot Chats.html を開いて、ボタンをブックマークバーへドラッグします。Teams で押し、開いた Copilot のタブでもう一度押します。

この版でできることと確かめた範囲は、ダウンロードのページにあります。
