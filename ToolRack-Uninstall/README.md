# Tool Rack の削除

Tool Rack を Windows から削除するバッチです。

[Uninstall-ToolRack.bat](Uninstall-ToolRack.bat) をダウンロードし、ふだん使うユーザーのままダブルクリックします。

- Tool Rack の自動起動、右クリックメニュー、常駐の処理、本体を削除します。
- インストール先は自動起動と右クリックメニューの登録から探すので、場所を指定する必要はありません。
- 保存済みの画像や文書、Tool Rack と関係のないアプリは残します。

隔離した環境の Windows PowerShell 5.1 で確認しています。職場のパソコンでは未確認です。
